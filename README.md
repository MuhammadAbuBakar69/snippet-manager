# Code Snippet Manager Starter Code

A dark IDE-style code snippet vault built with React and localStorage.

## Features
- **Snippet Library**: Store and organize snippets across JavaScript, Python, CSS, SQL, HTML, TypeScript, etc.
- **Search & Language Filters**: Instant client-side filtering by code title, description, or programming language.
- **Copy to Clipboard**: Quick copy button with visual feedback indicator.
- **IDE Syntax Window**: Dark themed code preview in `<pre><code>` with monospace font.
- **Add / Delete Snippets**: Create custom snippets with descriptions and persistent localStorage saving.
